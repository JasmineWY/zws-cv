# zws-cv

这是一个基于单页 HTML 的个人简历网站仓库。页面文件位于根目录：`index.html`，你可以直接在浏览器打开该文件或将其部署为 GitHub Pages 以生成公开的简历网址。

网站（Pages）地址（若已部署）：

- GitHub Pages（预期地址）：https://JasmineWY.github.io/zws-cv/
- 源文件（仓库）：https://github.com/JasmineWY/zws-cv/blob/main/index.html

如何自定义

1. 打开并编辑 `index.html`，将其中的占位信息替换为你的真实信息：姓名、邮箱、电话、城市、学校、实习/项目细节等。
2. 将你的 PDF 简历上传到仓库（例如 `resume.pdf`），并在 `index.html` 中把“下载 PDF 简历”的链接指向该文件。

如何部署为 GitHub Pages（快速步骤）

1. 进入仓库页面 → Settings → Pages。
2. 在 "Source/Branch" 选择分支（例如 `main`）和文件夹（选择 `/` 根目录），点击保存。
3. 等待几分钟，页面会显示 “Your site is ready to be published at” 并给出最终 URL，通常形式为 `https://<用户名>.github.io/<仓库名>/`。

排查提示

- 若访问 404：确认 `index.html` 在你选定的发布分支的根目录，等待几分钟并清空缓存重试。
- 若仓库为私有或组织受限：检查仓库或组织的 Pages 权限设置。
